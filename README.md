# 낙서.zip — 설치파일 배포

가볍고 빠른 **로컬 우선 블록 메모장** 낙서.zip 의 설치파일을 내려받는 곳입니다.
(소스 코드는 비공개입니다. 이 저장소에는 설치파일과 자동 업데이트 정보만 올라옵니다.)

## 내려받기

오른쪽 **Releases → 최신 버전**의 Assets 에서 OS 에 맞는 파일을 받으세요.

| OS | 파일 |
|----|------|
| Windows | `nakseo_x.y.z_x64-setup.exe` (권장) 또는 `.msi` |
| macOS (Apple Silicon) | `nakseo_x.y.z_aarch64.dmg` |
| macOS (Intel) | `nakseo_x.y.z_x64.dmg` |
| Linux | `.AppImage` · `.deb` · `.rpm` |

- 아직 코드서명 전이라 설치 시 "확인되지 않은 앱" 경고가 뜰 수 있어요. Windows 는 `추가 정보 → 실행`.
- 한 번 설치하면 이후 버전은 **앱을 켤 때 자동으로 업데이트 안내**가 뜹니다.
- 메모는 내 컴퓨터에만 저장되고, 새 버전을 덮어 설치해도 그대로 남아요.
